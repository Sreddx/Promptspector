# Product Prompts

This folder contains the **product prompt templates** — the actual templates users will use in Promptspector.

Each template follows the PromptSpec format (see `prd/PROMPTSPEC.md`).

## Templates (MVP)
- `presentation.md` — Build a presentation
- `brief.md` — Write a brief/PRD
- `agent-runbook.md` — Define an agent spec
- `executive-email.md` — Draft an executive email

## Template Structure
Each file is a PromptSpec with:
- Predefined fields
- Variables (`{{var}}`)
- UI hints and examples
